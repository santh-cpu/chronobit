# ChronoBit
Choronobit aims to be not just a digital clock, but helps the user stay focused on their task without having the worry of missing out on important notifications, and work towards achieving their goals.


## How to execute 
1) Install platform io cli
2) To compile
	```
	pio run
	```
3) To upload the code into the device
	```
	pio run --target upload
	```
4) To access the serial monitor
	```
	pio run --target monitor
	```
